# bandabookkeepers-website

Source of [bandabookkeepers.com](https://bandabookkeepers.com) — the bookkeeping website of Banda Bookkeepers, the bookkeeping desk of Think Mybiz Accountants and Tax Practitioners (Pty) Ltd ([thinkmybiz.co.za](https://www.thinkmybiz.co.za)).

## How it works

- Static HTML served from the repository root by Hostinger (auto-deploy from `main`).
- Pages are generated by `_src/build.py`: edit content there, then run `python3 _src/build.py` from the repository root and commit the output.
- Hand-edited (not generated): `assets/`, `contact.php`, `.htaccess`.
- `contact.php` emails enquiries to accounts@thinkmybiz.co.za. SMTP credentials are read from a file outside every web root and outside Git (see the comments in the file); never commit credentials.
- Links to Think Mybiz carry `?ref=bandabookkeepers` so referrals can be tracked.
